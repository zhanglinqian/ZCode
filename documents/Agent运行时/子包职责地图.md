# Agent CLI 子包职责地图

> 范围：apps/zcode-cli 下 18 个子包 + tools 的职责，以及 CLI 入口分发链。代码基准：main@29628c9（v3.14.3）；核对日期：2026-10-10。

## 入口链

```
bin "zcode" → packages/cli/dist/zcode.cjs
  → packages/cli/src/main.ts        （区分 protocol-server / TUI / plugin-host 调用模式；stderr/console 边界）
  → packages/cli/src/run.ts         （子命令分发）
     ├─ TUI：cli/src/tui-command.ts（runTuiCommand）
     │    → cli/src/tui-runtime-loader.ts → @zcode/tui（tui/src/tui.tsx 的 runTui，主界面 tui/src/app.tsx）
     │    （TUI 调用判定：cli/src/tui-stderr.ts 的 isTuiInvocation，默认首 positional 为 tui）
     └─ 其他子命令：cli/src/ 下各 *-command.ts
```

发行包层面 `zcode --web` 启动 Web、无参数进 TUI、其他参数交给 Agent CLI（见根 `README.md`「ZCode 命令行版」）。

## tools/ 与 scripts/

- `tools/prompt-trajectory`（`@zcode/prompt-trajectory`）：OpenAI 协议 trajectory 记录器，用于检查 CLI prompt 组装（record/derive/model-io 子命令）。
- `tools/typescript`：共享 TS 工程配置。
- `scripts/`：clean-dist、count-ts-lines、generate-bash-command-registry（bash 命令注册表，对应根 `registry:check`/`registry:generate`）、shadow-replay。
- `dependencies/native-search`：原生搜索依赖。

## 构建要点（apps/zcode-cli/package.json）

- turbo + pnpm workspace；`build`/`lint`/`typecheck` 经 `turbo run`；format 用 oxfmt、lint 用 oxlint（内部自跑，根 oxlint 豁免本目录）。
- SEA 单文件可执行：`sea`/`build:sea`（`packages/cli/scripts/build-sea.mjs`），根入口 `pnpm build:sea`。
- Node 24.14.0 / pnpm 10.33.2（与根 mise.toml 一致）。

## 相关仓库级占位包

- `packages/zcode-cua`（@zcode/zcode-cua）：Computer Use 的 **API 兼容占位包**——当前构建不带 Computer Use，所有 runtime surface（runtime、broker RPC、Helper 安装/启动/校验、PiP session client、native addon loader）返回 unavailable 且 fail-closed（纯 JS + .d.ts；`index.js` 的 `createComputerUseRuntime` 直接返回 isError 文本）。
- `packages/formal-proof`：Vite Web 应用「产品行为状态空间枚举器」，枚举对话场景中 compact/fork/goal/消息队列/query 编辑组合的决策行为（`src/model.ts` 构建 RunPhase/QueueState/GoalState/Decision 状态树；dev 地址 127.0.0.1:4176）。工具型，不进运行时链路。
