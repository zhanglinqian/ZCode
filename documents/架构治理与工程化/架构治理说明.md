# 架构治理与工程化说明

> 范围：architecture-policy 治理、根命令、lint/format/typecheck/knip、测试现状、构建与发行、第三方声明。代码基准：main@29628c9（v3.14.3）；核对日期：2026-10-10。

## 架构治理（architecture-policy.yaml）

- 可执行策略在根 `architecture-policy.yaml`：14 个模块（rpc/shared/provider/provider-node/services/session/storage/client/server/zcode-server-cli/ui/web/desktop/formal-proof/zcode-cli）全部登记；**唯一 `managed: true` 的是 storage**（layers: domain→app→adapters，publicEntrypoints: `packages/services/src/storage/contract.ts`，owner: desktop-settings），session 声明了 `publicEntrypoints: session/contract.ts` 但该文件不存在（见 [../代码不规范清单.md](../代码不规范清单.md)）。
- global 约束：`maxFileLines: 400`、`maxContractLines: 300`、`maxPublicMethods: 12`、`forbidCycles`、`forbidDeepImports`、`managedOnly: true`。
- 命令：`pnpm architecture:check [-- --changed]`、`architecture:report`、`architecture:baseline:update`（仅评审后的有意变更可刷新基线，CI 不自动刷）、`architecture:context <module-id>`（生成模块受控阅读包）。
- 治理工作流（`.agents/skills/architecture-governance/SKILL.md`）：改代码前 `architecture:check --changed` 定位模块 → `architecture:context` 读契约 → 先写 spec 再实现（单一 owner、单一路径、显式分层与边界、显式时序）→ 改后再 check，新违规与基线违规分开报告。
- 分层速查：domain 纯（无 IO、无 await 世界）；app 经 ports 决定副作用；adapters 执行 IO；跨模块边只走 public contract。

## Lint / Format 配置要点

- `.oxlintrc.json`：`max-lines: error, max 400`（skipBlankLines/skipComments）；overrides 对 `**/*.test.*`/`**/*.spec.*` 与 `**/i18n/locales/*.ts` 关闭 max-lines；ignorePatterns：`dist-release`、`packages/ui/src/components/ui`、`packages/ui/src/components/ai-elements`、`.agents/skills`、`packages/formal-proof`、`apps/zcode-cli`、`docs/electron`。
- `.oxfmtrc.json`：忽略第三方声明类文件。
- `tsconfig.base.json`：es2024 / nodenext / verbatimModuleSyntax / isolatedModules / noUncheckedIndexedAccess / composite。

## 构建与发行

- `pnpm bootstrap`（安装 + 桌面本地资源 + build:bootstrap）；`bootstrap:with-remote` 加远程资源（mock-cdn）。
- 桌面打包 `pnpm bundle:desktop`（细节见 [../桌面应用/构建与打包说明.md](../桌面应用/构建与打包说明.md)）。
- 命令行发行包 `pnpm build:zcode`（`scripts/build-zcode.mjs`）：构建 CLI/TUI、后端、Web → 收集原生库/worker/运行时依赖 → 组装 `dist/zcode/`（releases/<version>/tar.gz + sha256.txt + latest.json + install.sh）；需 `ZCODE_DIST_BASE_URL` 或 `--base-url`；`--skip-build` 复用产物重组包。
- SEA 单文件：`pnpm build:sea`（apps/zcode-cli 内 `build-sea.mjs`）。
- 原生搜索工具：`scripts/build-native-search-tools.mjs` / `package-native-search-tools.mjs`（跨平台 prebuild 处理见 `prepare-prebuilds*`）。
- 发布：release-it（根 `release` / `release:cli`）。

## 日志规范（根 AGENTS.md 摘要）

- UI 用 `packages/ui/src/logger.ts`；Agent/session/runtime 服务日志用 `createServiceLogger(scope)`（`packages/services/src/logger/serviceLogger.ts`）。
- `debug`＝协议原始数据/流式 chunk/逐条工具更新（生产不落盘）；`info`＝进程与会话生命周期、权限结果、一次性初始化；`warn`＝可恢复异常；`error`＝崩溃、握手失败、鉴权丢失。
- 不在日志、示例或提交中写入凭据、真实用户数据和内部服务地址。
