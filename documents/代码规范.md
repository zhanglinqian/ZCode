## 架构边界（强制）

| 规则 | 来源 |
| --- | --- |
| 文件 ≤ 800 行、契约 ≤ 300 行、公开方法 ≤ 12；禁止循环依赖、深导入（forbidDeepImports） | `architecture-policy.yaml` global |
| 跨模块边只走 public contract/entrypoint；domain 纯（无 IO）、app 经 ports、adapters 执行 IO | `architecture-policy.yaml` + `.agents/skills/architecture-governance/SKILL.md` |
| 改代码前 `pnpm architecture:check --changed` + `architecture:context <module-id>`；先更新 spec 再实现 | `.agents/skills/architecture-governance/SKILL.md`、根 `AGENTS.md` 核心原则 |
| 单一状态所有者、单条写入路径；明确事件顺序与幂等边界；不能用超时掩盖同步问题 | 根 `AGENTS.md`「实现与验证」 |
| UI 禁止：直接调用 Repo、Service 引用 Runtime 具体实现、跨域导入实现细节、循环依赖 | 根 `AGENTS.md`「UI 与平台边界」 |
| 跨包导入使用公开入口（package exports），遵守现有路径别名 | 根 `AGENTS.md`「实现与验证」 |
| 会话控制核心（`packages/session-control/src/**`）只依赖契约与注入端口，禁止导入 node/electron/react/zustand 等环境与宿主实现，禁止使用 `process`/`window`/`fetch`/`setTimeout`/`setInterval`/`Date` 全局 | `.oxlintrc.json` overrides（`no-restricted-imports` + `no-restricted-globals`）、`scripts/architecture/session-control-boundary.mjs` |

## 测试（强制）

| 规则 | 来源 |
| --- | --- |
| **App 业务单测已退役**：不新增或恢复 App 业务单测 `test`/`spec` 或 `contract.test.ts`；保留 CLI、CUA、E2E、浏览器验收和工程门禁测试 | 根 `AGENTS.md`「命令与仓库结构」、`docs/testing/unit-test-quality.md` |

| 未执行、零收集、平台跳过或环境失败均不代表测试通过 | `docs/testing/pre-push-hook.md` |

## 进程与状态（强制）

| 规则 | 来源 |
| --- | --- |
| Main 只做窗口、原生操作、进程调度和消息转发，不承载 task/session 业务状态 | 根 `AGENTS.md`「进程、协议与远程控制」 |
| 每窗口一个 window-scoped Local Host；本地 workspace 共享该 Host；不另建 Desktop Remote Host | 同上 |
| 手机远控复用桌面已有 Host attachment，不另起 Agent/Local Host/远程会话 | 同上 |
| desktop-continuous 与 web-remote-replayable 两种链路语义必须区分；改 stream/snapshot/queue/重连要同时验证两种 | 同上 |
| 外部 relay 与 Main 只做鉴权、配对、心跳、转发及 attachment 调度，不保存业务状态 | 同上 |
| busy/running 输入由 CLI/runtime `CommandInbox` 串行 admission；Renderer 只留草稿与 pending optimistic overlay；保留 owner/lease 与 stale run 防护 | 同上 |
| stdio 协议改动必须同步更新 `packages/shared/src/zcode-protocol/index.ts`（严格类型 + 运行时校验） | 同上 |

## UI（强制）

| 规则 | 来源 |
| --- | --- |
| 组件经 `packages/ui/src/hooks/` 访问服务；平台操作经 `IPlatformService`（`packages/shared/src/platform.ts`），不直接调 `window.zcode` | 根 `AGENTS.md`「UI 与平台边界」 |

| 修改 UI 前读 `DESIGN.md`；插件商店相关 UI 前读 `CONTEXT.md` | 根 `AGENTS.md`「命令与仓库结构」 |
| 复用 `packages/ui` 已有组件，兼顾桌面与手机 Web、三平台、主题与国际化 | 根 `AGENTS.md`「UI 与平台边界」 |

## 日志（强制）

| 规则 | 来源 |
| --- | --- |
| UI 用 `packages/ui/src/logger.ts`，不用 console.log / window.zcode?.log | 根 `AGENTS.md`「日志」 |

| 日志/示例/提交不写凭据、真实用户数据、内部服务地址 | 同上 |
