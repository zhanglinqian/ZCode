# 服务访问与状态管理说明（packages/ui）

> 范围：UI 层如何访问服务（hooks）、Zustand store 的组织与同步、渲染层日志。代码基准：main@a4b44451（v4.0.0）；核对日期：2026-11-25。

## hooks = 服务访问的唯一入口

`packages/ui/src/hooks/`（111 个文件；`index.ts` barrel 注释明确「组件应通过 hooks 访问服务，不再直接使用 services.* 或 window.zcode.*」）：

- 服务上下文：`useServices.tsx`（React Context 提供 `IServiceAccessor`，来自 @zcode/services）、`useWorkspaceServices.tsx`。
- 平台操作：`usePlatform.tsx`（消费 `IPlatformService`，见 `packages/shared/src/platform.ts`）。
- 领域服务 hook：`useTerminalService.ts`、`useSettingService.ts`、`useGitRepository.ts`、`useZCodeSessionService.ts`、`useZCodeTaskService.ts`、`useSkills.ts`、`usePlugins.ts` 等。

v4.0.0 新增的四个域（相对 v3.14.3）：

- Bot 群组：`useBotBoundGroups.ts`（机器人绑定群组投影）、`useBotGroupTask.ts`（群组任务上下文与渠道来源）、`useBotGroupMemberNames.ts`（群成员姓名）、`useBotPrivateDeliveryRetry.ts`（私聊投递重试）。
- Source Server：`useSourceServerStatuses.ts`、`useSourceServerDisplayNames.ts`、`useSourceServerManagementSnapshot.ts`、`useSourceServerOperationLogs.ts`。
- GenUI：`useGenUi.ts`（GenUI 卡片宿主，取 `genUiService` 与 `pluginSandbox`）。
- Web 远控：`useWebRemoteControlStatus.ts`、`useWebRemoteControlTaskOpen.ts`。

其余新增：`RemoteProjectPresentationContext.tsx`、`useBrowserSitePermissions.ts`、`useBuiltinAgentCli.ts`、`useComposerConnectionSwitch.ts`、`useImageFilePreview.ts`、`useRemoteConnectionProfileEditor.ts`、`useStartPlanEntitlement.ts`、`useToolPresentationHostCapabilities.ts`、`useVulnerabilityReportUrl.ts`、`useWorkspaceProviderConfigFile.ts`。预装工具的 `usePreinstalledToolsState` 是 `packages/ui/src/preinstalled-tools/PreinstalledToolsDialog.tsx` 内部局部 hook，不在 hooks 目录。

v4.0.0 已删除（不再存在于磁盘）：`useGroupedTaskView.ts`、`useActiveTaskSnapshotMeta.ts`、`usePluginCreator.ts`、`workspaceTaskListDisplayGroups.ts`、`workspaceTaskListOptimisticOverlay.ts`、`workspaceTaskListRefreshSignatures.ts`、`useLocalWorkspaceScopes.ts`、`useWorkspaceTaskLists.ts`。

硬规则（根 AGENTS.md「UI 与平台边界」）：组件通过 hooks 访问服务；平台操作通过 `IPlatformService`，**不直接调用 `window.zcode`**；禁止 UI 直接调用 Repo、Service 引用 Runtime 具体实现。

## Zustand store（packages/ui/src/store/，48 个文件）

| store | 职责 |
| --- | --- |
| `zcodeSessionStore.ts`（+ Types/Selectors/TaskSlice/WorkspaceSlice/Navigation） | 核心会话 UI 状态，按 workspace 分桶（一个 tab 一个 workspace）；暴露 E2E bridge `window.__zcodeSessionStoreE2E` |
| `index.ts` | 全局 UI 设置：主题、字号、通知偏好、登录入口、代码预览设置；经 BroadcastService（频道前缀 `state:`）跨窗口同步，部分偏好写 localStorage |
| `tabStore.ts` + `TabStoreProvider.tsx`、`StoreProvider.tsx` | tab 与 store 的 React 装配 |
| `mcpStore.ts` 系列（+Desktop/Helpers/Migration/StatusList） | MCP 服务状态 |
| `pluginStore.ts` / `pluginManagementStore*`、`skillStore.ts`、`subagentsStore.ts`、`commandsStore.ts`、`hooksStore.ts` | 插件/技能/子代理/命令/hooks |
| `remoteWorkspaceSessionStore.ts`（经 package exports 暴露给宿主）、`tabWorkspaceIdentity.ts` | 远程工作区会话与身份 |
| `sourceServerStatusRegistry.ts`、`sourceServerDisplayNameRegistry.ts`、`sourceSettingsServiceStore.ts` | Source Server 域：状态聚合 / 显示名注册表（`WeakMap` 按服务实例隔离，供 `useSourceServer*` 订阅）、source-settings 服务登记与释放 |
| `serviceAuthorityKey.ts` | 服务实例 → authority id 映射（WeakMap）；同路径/identity 可同时存在于 Controller 与多个 Source，按路径分桶会让 in-flight Promise 跨 RPC authority 复用 |
| `browserRecentVisitsStore.ts`、`embeddedBrowserPermissionStore.ts` | 内嵌浏览器：最近访问记录（按 workspace/session 分桶，限量写 localStorage）、权限弹窗队列（main 经 IPC 推送，用户决策后出队） |
| `subagentsStoreLoading.ts` | 子代理列表加载去重（键 = service authority + workspace + provider） |
| `workflowRunSavedStore.ts` | 「这次 run 对应哪个已保存工作流」的读缓存（磁盘定义仍是唯一权威） |
| 其余 | `modelTrajectoryStore.ts`、`taskQueryCacheStore.ts`、`whiteboardStore.ts`、`savedWorkflowStore.ts`、`offPeakTaskStore.ts`、`automationManagementStore.ts`、`conversationShareSelectionStore.ts`、`composerAttachmentUploadStore.ts`、`codeCommentPreviewStore.ts`、`workspaceHookReviewStore.ts`、`subagentsContextStore.ts`、`alertDialogStore.ts`、`confirmDialogStore.ts`、`dynamicWorkflowAvailabilityStore.ts`、`codingPlanQuotaResetState.ts` |

纪律（根 AGENTS.md）：

- 广播同步的主题、语言等字段需要**防止回环**（收到广播不得再次广播）。
- UI 局部状态不应被误当作服务端事实；服务端权威状态经服务/RPC 投影。
- hooks 中含 JSX 的文件使用 `.tsx`。

## 渲染层日志（packages/ui/src/logger.ts）

UI 统一日志门面，**不直接使用 `console.log` 或 `window.zcode?.log`**（根 AGENTS.md「日志」）：

- 生产构建（vite PROD / NODE_ENV）所有级别 no-op，避免 console 格式化与 IPC 转发拖慢渲染主线程。
- 开发态输出 console（前缀 `formatLogPrefix("ui")`，来自 @zcode/shared），info/warn/error 经 `window.zcode.log` 桥转发到桌面主进程（debug 不转发）。
- 开关 `__ZCODE_RENDERER_DISABLE_LOGGING__`；提供 `isLoggerLevelEnabled` guard（已从内部函数改为 `export`），供调用方在构造重 payload 前退出。

注意：文件注释残留 Vitest 字样，但现存测试统一为 node:test（见 [../代码不规范清单.md](../代码不规范清单.md)）。

## UI 的宿主装配

web 与 desktop renderer 都从 `@zcode/ui` import `Root`/`AppErrorBoundary`/`ZCodeIntlProvider`/`styles.css`；平台差异（真实原生 vs Web 降级）由各自宿主注入的 `IPlatformService` 承担，UI 组件不感知宿主类型。
