## 设计系统硬约束（根 DESIGN.md）

- `text-ui-*` 字号阶梯是全仓强制约束：UI 组件必须用 `text-ui-xl/lg/base/caption/sm/xs`；禁止 Tailwind 内置 `text-base/sm/xs` 与任意字号（`text-[13px]`、内联 font-size）。例外：代码/Diff/终端渲染用独立数值设置；移动端防 iOS 聚焦缩放的固定 token `text-mobile-input-safe`（16px）不是通用层级 token。
- 界面字号缩放只改 `--ui-font-size`，**绝不动 html/documentElement 的 fontSize**。
- 主题：System / Light（Zai Light）/ Dark（Zai Dark）；语义色 token（brand/accent/surface/card/popover/diff/idle-task 等）见 DESIGN.md 色板章节。
- 产品气质：calm、dense、operational；避免营销式大间距、渐变、整面品牌填充。

## 浏览器设计模式运行时（packages/design-runtime）

`packages/design-runtime` 是内置浏览器「设计模式」的**纯 TS 运行时**：生成并解析注入到 guest 页面的脚本，支撑「在浏览器里点选元素 → 改样式 → 写回本地 HTML 源码」。**无 React、无宿主依赖**，唯一依赖 `parse5`。

> ⚠ **消歧**：它与本文件下方的 ZCode 自身设计系统（根 `DESIGN.md`）**无关**，是命名巧合。design-runtime 服务的是「用户在 ZCode 内置浏览器里编辑**自己的网页**」，产出物是写回本地源文件的 style 属性 / CSS 变量；与 ZCode 的 UI token 体系没有共享。真正的设计依据是根 `docs/browser-use/2026-11-03-browser-design-mode-spec.md`。

**分层**（约 2074 行，10 个源文件 + `CONTRACT.md`）：

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 契约 | `src/contract.ts`（192） | 宿主↔页面全部数据形状：`DESIGN_RUNTIME_VERSION="22"`、`DESIGN_PAGE_LIMITS`（长文/短文/token/数组/事件数上限）、`PageElementSnapshot`、`DesignEditableValues`、`DesignRuntimeCommand`（14 个命令）、`DesignRuntimeEvent`（4 种）、`DesignRuntimeReply`、`DesignTweakControl` |
| 页面侧 | `src/elementInspector.ts`（399） | 元素读取器；`.toString()` 后注入页面，**函数体必须自包含** |
| 页面侧 | `src/pageRuntime.ts`（640） | `installDesignRuntime`：closed shadow root 浮层（hover/selected/badge）、`window.postMessage` 上报、宿主下行 `run(command)` |
| 页面侧 | `src/pageSignals.ts`（43） | 读 `data-zcode-design` 标记、`:root`/`html` 的 CSS 变量名、`data-variant` 方案、`section.slide` 数量 |
| 宿主侧 | `src/hostScripts.ts`（309） | 安装/命令脚本生成 + **防伪造**解析器（每个字符串/数组按 `DESIGN_PAGE_LIMITS` 截断） |
| 宿主侧 | `src/designMessages.ts`（115） | `parseCssColor` / `toHexColor` / CSS 变量 → 控件映射 |
| 宿主侧 | `src/sourceEdit.ts`（322） | 用 `parse5` 把选中元素映射回本地 HTML 源码并重写；**对不上就返回 `null`，宁可不写** |

**消费方**：唯一消费方是 `packages/ui`（`src/browser-use/useBrowserDesignRuntime.ts`、`useBrowserDesignMode.ts`、`useBrowserDesignSourceWriter.ts`、`BrowserDesignInspector.tsx`、`BrowserDesignFields.tsx`、`browserDesignProperties.ts`、`src/lib/webElementPickerScript.ts`、`src/lib/webElementContext.ts`）。`packages/desktop` 与 `packages/web` **不**直接依赖它。

**接入现状**：`build`（tsc）与根 `pnpm typecheck` 已接入；**无单测**（不在工程测试清单）；`architecture-policy.yaml` 登记为受管模块（`owner: browser`，`layers: {app: .}`）；`private: true` 不发布。

## 刻意不拆（覆盖矩阵登记）

以下子域**不单独建链路文档**，以本清单 + 所属模块文档为准：Git 面板族、设置页族、quickpick/shortcuts/presentation、workspace 文件树/搜索、previewPane 渲染器、login/onboarding/feedback、prompt-editor/mentions。理由：均为无独立跨进程状态机的展示层，状态归上述 store/服务。若某子域引入独立状态机或跨进程链路，再立专题并更新 [../模块覆盖矩阵.md](../模块覆盖矩阵.md)。
