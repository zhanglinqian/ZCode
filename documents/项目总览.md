# ZCode 项目总览

> 范围：产品定位、技术栈、仓库布局、顶层架构与主流程导航。本文只导航不替代专题；细节见各模块文档。代码基准：main@29628c9（v3.14.3）；核对日期：2026-10-10。

## 产品定位

ZCode 是 AI 编程工作台，提供三种形态，同一套 Agent 运行时：

1. **桌面应用**（Electron，`packages/desktop`）；
2. **浏览器界面**（`packages/web` + `packages/server`，或命令行 `zcode --web`）；
3. **终端 Agent**（`apps/zcode-cli`：TUI 与 Agent CLI）。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 工具链 | Node 24.14.0、pnpm 10.33.2（`mise.toml`）、TypeScript 6、turbo（zcode-cli 内）、oxlint / oxfmt |
| 桌面 | Electron 41、electron-builder 26、tsup（main/preload/host/scheduler）+ Vite 8（renderer）、node-pty、ssh2 |
| 前端 | React 19、Zustand 5、Tailwind 4、radix-ui/shadcn、streamdown、xterm、lexical、@xyflow/react |
| 服务端 | Hono、ws、node:sqlite（任务索引）、croner、zod 4 |
| Agent | AI SDK 6.x（@ai-sdk/anthropic、openai、openai-compatible）、受限 CEL 表达式引擎（model-option-map） |

## 顶层架构

```
┌─ Desktop ──────────────────────────────────────────────┐
│ Main（窗口/托盘/更新/IPC，无业务状态）                    │
│  ├─ Window Host × N（utilityProcess，每窗口一个）        │
│  │   ├─ local services（@zcode/services）               │
│  │   │    └─ Agent 子进程（apps/zcode-cli，stdio 协议）  │
│  │   └─ 远程连接注册表（SSH/WSL → 远端 agent）           │
│  ├─ cron scheduler（utilityProcess，派发回 main）        │
│  └─ Renderer（@zcode/ui，经 MessagePort 连 Host）        │
└─────────────────────────────────────────────────────────┘
┌─ Web / 命令行 ──────────────────────────────────────────┐
│ packages/server（Hono：/ws、/ws/host、/ws/remote/:id）   │
│   ├─ 同一套 local services + Agent 子进程                │
│   └─ remote/（SSH/WSL/Docker backend → 远端 agent）      │
│ packages/zcode-server-cli（supervisor 守护、更新、卸载） │
│ packages/web（浏览器端，connectViaWebSocket）            │
└─────────────────────────────────────────────────────────┘
手机远控：连接桌面已有 Host attachment（web-remote-replayable）
```

关键不变量（根 `AGENTS.md`）：Main 只做窗口/原生/调度/转发；每窗口一个 window-scoped Local Host；外部 relay 不存业务状态；busy/running 输入由 CLI 侧 `CommandInbox` 串行 admission；`workspaceIdentity` 管身份隔离、`workspacePath` 管文件操作。

## 常用命令速查

| 用途 | 命令 |
| --- | --- |
| 初始化 | `pnpm bootstrap`（远程资源：`pnpm bootstrap:with-remote`） |
| 桌面开发 | `pnpm dev:desktop` / `pnpm dev:desktop:test` |
| Web 开发 | `pnpm dev:web`（Web 5173 + 后端 3030） |
| CLI 源码 | `pnpm --filter @zcode/cli... build` |
| 类型检查 / Lint | `pnpm typecheck` / `pnpm lint` |
| 桌面打包 | `pnpm bundle:desktop [-- --os win --arch x64]` |
| 命令行发行 | `pnpm build:zcode --base-url <地址>` |

完整命令与环境变量见根 `README.md` 与 [架构治理与工程化/架构治理说明.md](./架构治理与工程化/架构治理说明.md)。
