# 双链路语义说明（desktop-continuous 与 web-remote-replayable）

> 范围：实时链路与恢复链路的区分、attachment 机制、workspaceIdentity 规则。代码基准：main@29628c9（v3.14.3）；核对日期：2026-10-10。

## 两种交付语义（必须区分）

| 链路 | 客户端 | 语义 | 入口 |
| --- | --- | --- | --- |
| `desktop-continuous` | 桌面 Renderer（受信 host） | 实时流：直接 live stream，同一 owner 与序列 | `packages/server/src/http.ts` 的 `GET /ws/host`（前置一次性 capability 校验） |
| `web-remote-replayable` | 浏览器 / 手机（terminal-client） | 恢复链路：snapshot + gap repair | `packages/server/src/http.ts` 的 `GET /ws`（固定 terminal-client 模式） |

设计示意（`.agents/skills/architecture-governance/SKILL.md`）：

```
desktop: continuous ── direct live stream ──┐
                                           ├─ same owner and sequence
mobile:   replayable  ─ snapshot + gap repair ┘
```

`/ws/host` 的鉴权：`POST /api/rpc-host-capability` 签发一次性令牌，连接时带 `ZCODE_RPC_HOST_CAPABILITY_HEADER`，`hostCapability.ts` 的 store `consume` 失败即 401。RPC 侧经 `createZCodeAgentConnectionScope` 按 clientMode 区分 `trusted-host-relay` / `terminal-client`；非 trusted 客户端对 `IProviderProvisioningTargetService` 的 override 直接抛错（凭据保护，`http.ts` 注释）。

**修改 stream、snapshot、queue 或重连时，必须同时验证两种语义**（仓库根 `AGENTS.md`）。

## attachment 机制（手机远控）

- 手机远控**连接桌面已有 Host attachment，复用会话运行时**；不为手机另起 Agent、Local Host 或远程会话（根 `AGENTS.md`）。
- `packages/desktop/src/host/windowHostAttachmentRegistry.ts`：按 attachmentId 跟踪 renderer/移动端挂载的 scoped 服务端口；支持 detach、`detachStaleRemoteSessionAttachments`（清 stale）、`detachRemoteSessionAttachments`。
- Renderer 侧远程 session 服务构建：`packages/desktop/src/renderer/src/remoteWorkspaceServicePortBridge.ts` + `remoteWorkspaceSessionServices.ts` → `@zcode/ui` 的 `registerRemoteWorkspaceSession`。
- 手机/浏览器从 Web 侧进入：`@zcode/client` 的 `connectViaWebSocket`（`packages/client/src/websocket.ts`）把 WebSocket 包成 `ISocket` 走同一 RPC 框架；`?remote=<id>` 参数连 `/ws/remote/<id>`。

## workspaceIdentity 规则（根 AGENTS.md「Workspace Identity」）

- `workspaceIdentity` 用于身份隔离；`workspacePath` 用于文件操作、命令 cwd、Git 和路径展示。
- 身份 key 统一为 `workspaceIdentity?.trim() || workspacePath`，适用于去重、绑定、缓存、队列、持久化和请求关联。
- 远程链路贯穿传递 `workspaceIdentity` 与 `remoteSessionId`，不得仅按路径匹配。
- 新接口保留本地路径 fallback；远程 identity 复用现有构造和解析工具，不在业务代码中手写格式。
- UI 侧相关 store：`packages/ui/src/store/tabWorkspaceIdentity.ts`、`remoteWorkspaceSessionStore.ts`（经 package exports 暴露给宿主）、`remotePinnedTaskStore.ts`、`remoteTimelineTaskStore.ts`。

## 已接受输入的所有权（busy/running）

已接受的 busy/running 输入由 CLI/runtime 的 `CommandInbox` 串行 admission（`apps/zcode-cli/packages/bootstrap/src/zcode-protocol-v4/command-inbox.ts`）；Renderer 只保留未提交草稿与 pending optimistic overlay；Host owner/lease 负责路由。保留 owner/lease、跨 Host 路由和 stale run 防护，不能仅根据单一路径删除边界判断。详见 [../Agent运行时/会话运行时与CommandInbox说明.md](../Agent运行时/会话运行时与CommandInbox说明.md)。

## 外部 relay 与 Main 的边界

外部 relay 与 Electron Main 只做鉴权、配对、心跳、转发及 attachment 调度，**不保存任务队列、快照等业务状态**（根 `AGENTS.md`）。
