# 桌面构建与打包说明

> 范围：packages/desktop 的开发环境、运行时资产准备与 electron-builder 打包。代码基准：main@29628c9（v3.14.3）；核对日期：2026-10-10。

## 开发环境分档

开发命令在仓库根执行，由 `scripts/dev-desktop-env.mjs` 分档（见根 `package.json` scripts）：

| 命令 | 环境 |
| --- | --- |
| `pnpm dev:desktop` | 等同 `dev:desktop:prod`（生产服务配置） |
| `pnpm dev:desktop:test` | 测试环境 |
| `pnpm dev:desktop:bytecode` | 生产 + agent 字节码模式 |
| `pnpm dev:desktop:remote-prod` | 远程生产（`scripts/dev-desktop-remote-prod.mjs`） |

包内 dev 链路（`packages/desktop/package.json`）：`pre-dev`（`scripts/ensure-local-runtime-assets.mjs` 校验本地资产 + 清空 out/）→ `dev:local-cli`（tsup --watch × 3 + vite dev + `scripts/dev.mjs` 启动 Electron；dev.mjs 等 `out/.main-build-ready` 等 marker）。

独立数据目录用 `ZCODE_DATA_BASE_DIR`（如 `ZCODE_DATA_BASE_DIR="$HOME/.zcode-dev-home" pnpm dev:desktop:test`，见根 `README.md`）。

## 运行时资产准备

`prepare:runtime-assets`（`scripts/prepare-runtime-assets.mjs`）串联：

1. `prepare:remote-assets` → 根 `scripts/prepare-prebuilds.mjs`（远程跨平台二进制，可用 `ZCODE_SKIP_REMOTE_ASSETS=1` 跳过；根 `pnpm prepare:remote-assets` 单独执行）。
2. `prepare:agent-bundle` → `scripts/prepare-agent-node-bundle.mjs` / `stage-agent-bundle.mjs`（内置 agent JS bundle）。
3. `prepare:native-search`（原生搜索工具）、`prepare:browser-import-helper`、`prepare:macos-window-bounds`（native/ 小工具）。
4. `prepare:build-meta` → `scripts/build-metadata.mjs`。

远程功能（SSH/WSL）开发：先根 `pnpm bootstrap:with-remote`（含 mock-cdn），再 `pnpm dev:desktop`；开发态远端资源取自本地 `packages/desktop/mock-cdn` 与本地构建产物，经 SFTP 上传，不访问 CDN。

远端资源地址：`src/main/remoteCdn.ts` 解析（默认 `https://cdn-zcode.z.ai`，可被 `ZCODE_CDN_BASE_URL` / 编译期 `__ZCODE_CDN_BASE_URL__` 覆盖）；`src/main/desktopRuntimeEnv.ts:204-212` 开发态优先 mock-cdn。

## 生产构建与打包

- `build` = `prepare:runtime-assets` + `build:no-runtime-assets`；后者 = `prepare:build-meta` + `scripts/run-production-build.mjs`（清理并重建 out/main、out/host、out/preload、out/renderer）。
- `bundle` → `scripts/bundle.mjs`：electron-builder 打包聚合入口，含目标平台解析、asar 校验（`@electron/asar`）、原生包策略（`desktop-native-package-policy.mjs`）、运行时依赖闭包（`runtime-dependency-closure.mjs`）、NSIS patch（`patch-nsis-install-section.mjs`）。
- `electron-builder.config.js`：appId/productName/entitlements 等，身份来自 `scripts/desktop-product-identity.mjs`。
- 根入口：`pnpm bundle:desktop [-- --os mac|win|linux --arch x64|arm64]`，默认 macOS arm64，输出 `packages/desktop/dist/`（见根 `README.md` 打包章节）。
- `audit:bundle-size`：产物体积审计。
- `postinstall`：`scripts/node-pty-rebuild.mjs`。

## 相关环境变量

| 变量 | 用途 |
| --- | --- |
| `ZCODE_DATA_BASE_DIR` | 应用数据基目录（数据写入其下 `.zcode/`） |
| `ZCODE_CDN_BASE_URL` | 覆盖远端资源 CDN 地址 |
| `ZCODE_SKIP_REMOTE_ASSETS` | =1 跳过 remote assets 准备 |
| `ELECTRON_RENDERER_URL` | 开发态 renderer dev server 地址 |

## 交叉脚本（仓库根）

桌面相关的根级脚本：`scripts/bootstrap.mjs`（bootstrap / bootstrap:with-remote）、`scripts/build-desktop-agent-bytecode.mjs` + `compile-desktop-agent-bytecode.cjs`（agent 字节码）、`scripts/build-native-search-tools.mjs` / `package-native-search-tools.mjs`（原生搜索工具构建与打包）、`scripts/doctor-macos-release-app.sh`（macOS 发行自检）。
